# Project-defined RAG knowledge base

This directory contains the bounded corpus used by the optional RAG prototype.
It is derived from this coursework project's confirmed data contract, issue
taxonomy, output logic, and human-review controls. It is **not** a bank policy,
regulatory rulebook, underwriting guide, or source of credit criteria.

The corpus may support readiness explanations and semantic interpretation only.
It must not be used to assess affordability, default risk, approval, rejection,
interest, pricing, or credit limits.

The RAG path retrieves only from the two Markdown files in this directory. It
does not index final-test labels, evaluation results, customer data, course
slides, or the trade-off report.
